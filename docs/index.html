What it actually does

It works through your task list in parallel, skips anything already done, retries whatever breaks, remembers exactly where it stopped, and hands you a pass/fail report at the end. Point it at 100+ jobs and it grinds through them while you get on with something else.

safety

Tasks are inert, the binary is explicit

Task text is handed over as a single argument with shell=False, so metacharacters stay text and can never become commands. The AI binary is required through --bin and is never auto-guessed — a wrong guess silently runs the wrong program.

FAQ

The questions every AI asks before installing.

Does it work with my AI?+
Yes. Any MCP-compatible client: opencode, Claude Code, Cursor, Cline, Windsurf. It degrades gracefully elsewhere.
Is it free?+
MIT licensed, free forever. No API keys required for the core tools.
How long to install?+
One prompt. The AI clones, installs, wires and runs the smoke test. About 60 seconds.
Does it slow my AI down?+
No. Cached reads are 0.49ms and prompts are 50% shorter. It makes your AI faster.
Can I use just some tools?+
Yes. All current tools are exposed, but your AI only calls what it needs. Unused tools cost nothing.
