# stop-slop

Remove AI writing tells from any prose the agent generates (docs, READMEs, messages).

## Steps
1. Ban: em dashes (—), "delve", "moreover", "furthermore", "in today's", "game-changer", "leverage", throat-clearing openers ("Certainly!", "Great question!").
2. Short sentences. One idea each. No synonym stacking.
3. Read back once: if it sounds like a press release, rewrite plain.

## Rules
- Apply to user-facing prose only, never to code/logs.
- Plain > pretty. Human > brochure.
